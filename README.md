
# Hindustan Unilever Ltd. – Financial Analysis & Valuation
## 1. Project Overview
This project presents a comprehensive financial analysis and valuation of Hindustan Unilever Limited (HUL), one of India's leading FMCG companies.
The objective is to evaluate the company's historical financial performance, develop financial projections, analyse key financial ratios and estimate its intrinsic value using financial modelling and valuation techniques.

**Company:** Hindustan Unilever Limited  
**Industry:** Fast Moving Consumer Goods (FMCG)  
**Historical Period:** FY2017 – FY2026  
**Forecast Period:** FY2027 – FY2031  
**Currency:** INR (₹ Crores)  
**Tool:** Microsoft Excel
---
## 2. Project Objectives
- Analyse historical financial statements.
- Develop a three-statement financial model.
- Perform financial ratio analysis.
- Conduct common size financial statement analysis.
- Analyse historical financial trends.
- Prepare financial projections.
- Estimate intrinsic value using DCF valuation.
- Perform Comparable Company Analysis.
- Evaluate the company's financial performance and valuation.
---
## 3. Project Scope & Methodology
### A. Three-Statement Financial Modelling
Developed a financial model covering:
- Profit & Loss Statement
- Balance Sheet
- Cash Flow Statement
The model includes historical financial information and projected financial statements for FY2027–FY2031.
### B. Financial Ratio Analysis
Analysed the company's financial performance using:
- Profitability Ratios
- Liquidity Ratios
- Solvency Ratios
- Efficiency Ratios
- Market Ratios
- Operating Cycle Ratios

### C. Common Size Financial Statement Analysis
Performed common size analysis of HUL's Income Statement and Balance Sheet to evaluate the composition of financial statements over the historical period.
**Common Size Income Statement**
- Analysed expenses as a percentage of revenue.
- Evaluated profitability margins.
- Examined changes in the company's cost structure.
**Common Size Balance Sheet**
- Analysed assets as a percentage of total assets.
- Evaluated the composition of liabilities and equity.
- Examined changes in the company's asset and capital structure.
### D. Trend Analysis
Evaluated historical trends in revenue, profitability and other key financial metrics to understand the company's long-term financial performance.
### E. Discounted Cash Flow (DCF) Valuation
Developed a DCF valuation model using:
- Cost of Equity
- Cost of Debt
- Weighted Average Cost of Capital (WACC)
- Free Cash Flow
- Terminal Value
- Discounting Factor
- Enterprise Value
- Equity Value
- Implied Share Value
### F. Comparable Company Analysis
Performed relative valuation by comparing HUL with selected companies:
- ITC Limited
- Hindustan Foods Limited
- Godavari Biorefineries Limited
Valuation multiples considered:
- EV/Revenue
- EV/EBITDA
- P/E Ratio

## 5. Key Financial Observations
- Revenue increased from ₹33,162 Cr in FY2017 to ₹64,468 Cr in FY2026.
- Net Profit increased from ₹3,884 Cr to ₹10,136 Cr.
- EBITDA Margin improved from 19.08% to 23.33%.
- FY2026 net cash position was approximately ₹1,770 Cr.
- Interest Coverage Ratio stood at 33.43x in FY2026.
- The company demonstrated consistent operating performance and cash generation.
